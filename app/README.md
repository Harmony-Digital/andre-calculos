# App do Portal de Cálculos

Na pasta `app`, use Node.js 22 ou superior e `npm ci`. `npm run dev` abre o desenvolvimento local, `npm run check` confere formatação, lint, tipos, regras de negócio e build. `npm run test:e2e` verifica o navegador em 375 e 1440 pixels.

Leia as instruções em `../AGENTS.md`, os requisitos em `../PRD.md` e o andamento em `../plan.md`.

As fontes Source Sans 3 e Source Serif 4 são servidas localmente. As regras de preço, prazo, complexidade e estados ficam em `src/modules`. Nunca insira dados processuais reais nos testes.
